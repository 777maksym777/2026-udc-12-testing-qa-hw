# UDC Workshop 12 — Тестування та QA з AI

- **Слайди:** <https://koldovsky.github.io/2026-udc-12-testing-qa-slidev/>
- **Повні інструкції:** [`docs/walkthrough.md`](docs/walkthrough.md)

Домашнє завдання на **одній невеликій системі** — «Велопрокат громади»: ціна поїздки
за тарифами громади, чек, невеликий HTTP API і вебсторінка. Головне питання воркшопу —
**що насправді ловить ваш тест?** Тому тести з AI ви пишете двічі — з коду і зі
специфікації, — міряєте їхню якість мутаціями і розбираєте падіння за доказами.

**Дедлайн: 18.11.2026, 23:59 за Києвом (воркшоп 12 — останній, тому окремий дедлайн).**

## Що потрібно

- Node 22.5+ (`npm install` не потрібен — у репо немає жодної npm-залежності)
- Git Bash (на Windows), GitHub account, Agentic IDE в агентному режимі (Claude Code;
  Cursor — Agent; Copilot — Agent mode): AI має сам читати файли, писати тести й
  запускати команди
- Жодних API-ключів і хмарних акаунтів. Браузер з MCP чи трекер — лише для бонусу.

## Швидкий старт

```bash
gh repo fork koldovsky/2026-udc-12-testing-qa-hw --clone
cd 2026-udc-12-testing-qa-hw
git checkout -b ws12/<github-username>

npm test   # усі тести застосунку
```

Чесно попереджаємо: серед тестів застосунку є тест, який **інколи** падає без жодних змін
у коді. Якщо `npm test` червоний — запустіть ще раз (див. Task D); до того цей тест не
чіпайте.

Усі команди — у **Git Bash** (на Windows): у Windows PowerShell 5.1 частина з них не працює.

## Команди (з кореня репо)

```bash
npm test                  # усі тести застосунку
npm run test:unit         # лише unit-тести
npm run coverage          # покриття unit-тестами (вбудоване в Node)
npm run mutate            # мутаційне тестування (tools/mutate.mjs) — не раніше Task C
npm run test:repeat -- 30 # прогнати всі тести 30 разів (tools/repeat.mjs)
npm run test:tools        # тести самих інструментів
cd app && npm start       # API і сторінка на http://localhost:3000
```

## Що робите ви

| Задача | Що | Час |
|---|---|---|
| **Task A** | Тест-дизайн: тест-кейси AI з коду і зі специфікації, ваші кейси, трасування, чек-ліст | ~1 год |
| **Task B** | Автотести з коду і зі специфікації, класифікація червоних тестів, виправлення, звіти про дефекти | ~1,5 год |
| **Task C** | Покриття проти мутацій, тестові «запахи», AI посилює тести, правила для агента | ~1,25 год |
| **Task D** | Нестабільний тест: причина, а не повтор; тріаж чотирьох падінь CI | ~1 год |
| **Task E** (бонус) | Один шлях: e2e з AI-браузером / майстер тест-план / трекер через MCP | ~30–60 хв |

Разом ~5 годин без бонусу. Помітну частину цього часу агент працює сам. Порядок задач —
саме такий: `npm run mutate` не запускайте до Task C.
