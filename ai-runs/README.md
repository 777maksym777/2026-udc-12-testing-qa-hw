# ai-runs/

Сюди — **перші відповіді AI, дослівно**: такими, якими модель їх видала, до будь-яких ваших
виправлень, і **виводи прогонів**. Саме їх ми порівнюємо — що AI зробив сам і що ви потім
виправили. Не скорочуйте, не правте і не замінюйте пізнішою «кращою» відповіддю: усе, що
ви виправили, живе у ваших файлах у `docs/` і `app/`.

## Файли

| Файл | Задача | Що це | Що бачила сесія |
|---|---|---|---|
| `a1-from-code.md` | Task A | тест-кейси AI з коду | лише `app/src/` (копія з `main`) |
| `a2-from-spec.md` | Task A | тест-кейси AI зі специфікації | лише `docs/spec/tariffs.md` |
| `b1-from-code/*.test.js` | Task B | unit-тести AI з коду — без змін | лише `app/src/` + `package.json` (копія з `main`) |
| `b1-from-code.md` | Task B | фінальна відповідь агента до цих тестів | те саме |
| `b1-run.txt` | Task B | вивід `node --test "ai-runs/b1-from-code/*.test.js"` до виправлень | — |
| `b2-run.txt` | Task B | вивід `npm test` з тестами `app/test/spec/` до виправлень | — |
| `b1-rerun.txt` | Task B | той самий запуск тестів з коду після виправлень | — |
| `c-before.txt` | Task C | `npm run -s coverage` + `node tools/mutate.mjs` до посилення | — |
| `c-smells.md` | Task C | тестові «запахи», які знайшов AI | копія поточного `app/` |
| `c-strengthen.md` | Task C | фінальна відповідь агента «посиль тести» | репо |
| `c-strengthen.diff` | Task C | усі зміни агента (`git diff --cached`) | — |
| `c-after.txt` | Task C | `npm run -s coverage` + `node tools/mutate.mjs` після посилення | — |
| `c-with-rules.md`, `c-with-rules/*.test.js` | Task C | повторний прогін «з коду» з вашими правилами | `app/src/` з `main` + файл правил |
| `d-repeat-before.txt` | Task D | `node tools/repeat.mjs 30` до виправлення | — |
| `d-flaky-first.md`, `d-flaky-first.diff` | Task D | перша відповідь агента «тест іноді падає» і його зміни | копія `app/`, `tools/`, `package.json` з `HEAD` без файлу правил і без `docs/` |
| `d-repeat-after.txt` | Task D | `node tools/repeat.mjs 50` після виправлення | — |
| `d-ci-first.md` | Task D | тріаж чотирьох прогонів CI від AI | `ci/` + `app/` (копія з `main`) |
| `e-browser.md` / `e-test-plan.md` | Task E | лише для обраного бонусного шляху | — |

Зберігайте як `.md`, `.txt` або `.diff` — файли `*.log` git ігнорує. Виводи інструментів
зберігайте командами з `docs/walkthrough.md` (`node tools/…`, `npm run -s …`): так у файлі
не буде службових рядків npm.

## Шапка кожного `.md`

```markdown
- Інструмент і модель: <наприклад, Claude Code, Claude Sonnet>
- Дата: <РРРР-ММ-ДД>
- Що бачила сесія: <тимчасова тека і що в ній; або «репо + вказівка читати лише …»>
- Що було ввімкнено з пам'яті й глобальних правил: <нічого / що саме>
- Промпт (дослівно):

  > <...>

---

<відповідь AI дослівно>
```

Якщо агент сам записав відповідь у файл (як просять промпти) — додайте шапку над його
текстом, а сам текст не чіпайте. Якщо агент виконував команди чи читав файли —
достатньо його фінальної відповіді й файлів, які він створив; повний журнал сесії не
потрібен. Відповідь довга — лишайте повністю.

Якщо агент записав відповідь не туди, куди просили, — перенесіть її сюди і напишіть у
шапці, звідки взяли. Якщо замість відповіді він поставив питання — відповідайте лише
«вирішуй сам» і збережіть обидва його повідомлення.

Тести в `b1-from-code/` і `c-with-rules/` не правте навіть тоді, коли вони червоні: вони —
вимірювання, а не частина набору тестів застосунку. `npm test` їх не запускає.
